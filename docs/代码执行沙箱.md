# 代码执行沙箱

QUBE/回测的信号代码与研究实验代码经 `backend/services/sandbox.py` 执行：优先在 OpenSandbox 容器中隔离（数据经文件 API 以 CSV 传入，不挂载卷，兼容 Windows），Docker/沙箱服务未就绪时自动降级为进程内执行（无容器隔离，多处会显式标注）；覆盖 `/api/backtest/run-strategy`、QUBE `run_backtest` 与 QUBE `run_research_code`，因子研究页与工作流因子节点保持原生执行。

## 启用

客户端已随 `make install` 安装。要真正启用隔离，先启动 Docker Desktop，再单开一个终端跑沙箱服务：

```bash
make sandbox-server   # 实质执行 uvx opensandbox-server
```

## 状态查询

`GET /api/system/sandbox`：实际探测 opensandbox-server（HTTP 健康探测 + TCP 兜底，而非仅看包安装/配置开关），`active=false` 即当前为进程内降级；`note` 字段附带启用引导。

## 降级在哪里可见（offline 也有感知）

沙箱未就绪时，降级不是静默的，以下位置都会显式标注：

| 位置 | 形式 |
|---|---|
| 设置页「代码执行沙箱」卡 | 状态点 + 引导（未就绪时显示 `make sandbox-server` 命令），30s 自动刷新 |
| QUBE 新会话空态页 | 一次性提示条（仅未就绪时显示） |
| 回测记录详情（运行中心 / QUBE 策略工作台） | 执行环境徽标：绿点「沙箱中隔离执行」/ 黄点「进程内执行」，随 `metrics.sandboxed` 持久化 |
| QUBE 工具结果（`run_backtest` / `run_research_code`） | `sandboxed` 字段 + `sandbox_note` 提示语，agent 会在回复中转告用户 |
| 回测记录日志 / 后端日志 | `[INFO] 信号代码执行环境：…` / loguru WARNING |
