## 一、数据层：数据从哪来、长什么样、怎么用

**结论先行：数据后台已经包装好了，不需要你做任何预处理**。因子构建节点运行时会自动按
「股票池 + 时间区间」从本地 QMT 行情缓存（`data/cache/1d/*.parquet`）加载数据，
组装成可直接参与运算的「面板 DataFrame」注入求值环境。

### 1. 数据形态：面板 DataFrame

每个字段（如 `close`）是一个二维表：**行 = 交易日，列 = 股票代码**，值为当日该股票的字段值：

```text
close 面板示例（index=交易日, columns=股票代码）：

              000001.SZ   600000.SH   300750.SZ
2024-01-02       9.31        6.88      161.50
2024-01-03       9.28        6.85      158.20
2024-01-04       9.35        6.90      160.10
...               ...         ...         ...
```

所有算子都针对这种面板设计：

- **截面算子**（`RANK`/`ZSCORE`/`SCALE`）按**行**计算 —— 同一天所有股票之间比较；
- **时序算子**（`DELAY`/`MA`/`STD`/`TS_RANK`…）按**列**计算 —— 单只股票的时间序列；
- 面板之间可直接四则运算（自动按日期和股票对齐），如 `(high - low) / close`。

### 2. 求值环境里有什么

进入「因子构建（公式）/（代码）」节点后，以下变量**开箱即用**（大小写均可）：

| 变量 | 内容 | 来源 |
|------|------|------|
| `open` `high` `low` `close` | 开/高/低/收面板 | QMT 缓存 Parquet |
| `volume` `amount` | 成交量/成交额面板 | QMT 缓存 Parquet |
| `vwap` | 成交均价面板 | 派生：amount / volume |
| `returns` | 日收益率面板 | 派生：close.pct_change() |
| `adv20` | 20 日平均成交量面板 | 派生：MA(volume, 20) |
| 全部算子函数 | RANK/DELAY/CORR/RSI… | 本地算子库（对齐官网手册） |

### 3. 如何查看/检查数据

代码节点支持 `print`，输出会显示在**运行日志**中。不确定数据长什么样时，先跑一遍：

```python
print(close.shape)        # (交易日数, 股票数)
print(close.columns[:5])  # 前 5 只股票代码
print(close.tail())       # 最近 5 个交易日的数据
factor_data = RANK(close / DELAY(close, 20) - 1)
```

### 4. 数据从哪里补充

- 面板覆盖的股票 = 股票池所填代码（留空 = 本地全部已缓存股票）；覆盖的日期 = 起止日期区间。
- 某只股票没数据 → 先到「数据管理」页下载该股票日线；完全无数据时节点会给出明确报错提示。
- 本地缓存仅有**量价数据**，因此换手率/市值/财务字段暂不可用（见第三节标注）。

## 二、两种编写方式

### 1. 公式方式（无需编程基础）

在「因子构建（公式）」节点或因子构建器「公式模式」中直接输入表达式：

```text
# 20 日动量的截面排名
RANK((CLOSE / DELAY(CLOSE, 20)) - 1)

# 价量相关性
CORRELATION(CLOSE, VOLUME, 20)

# 复杂因子（官网示例）
RANK((CLOSE / DELAY(CLOSE, 20)) - 1) *
STDDEV((CLOSE / DELAY(CLOSE, 1)) - 1, 20) *
IF(CLOSE > DELAY(CLOSE, 1), 1, -1)
```

- 大小写均可（`rank` 等价 `RANK`）。
- 公式较复杂时可分多行、设中间变量，系统读取**最后一行**作为因子值。

### 2. 代码方式（推荐，易维护）

在「因子构建（代码）」节点或「代码模式」中编写 Python，把结果赋值给 `factor_data`：

```python
# 数据已自动加载为面板 DataFrame（见第一节），无需自己读数据
close_v = close          # 也可以直接用 CLOSE
volume_v = volume

# 计算 20 日收益率
ret20 = (close_v / DELAY(close_v, 20)) - 1
# 计算 20 日波动率
volatility = STDDEV((close_v / DELAY(close_v, 1)) - 1, 20)
# 计算成交量比率
volume_ratio = volume_v / DELAY(volume_v, 1)
# 动量信号 × 波动率方向 × 量能
momentum = RANK(ret20)
vol_signal = IF(volatility > DELAY(volatility, 1), 1, -1)
factor_data = momentum * vol_signal * SCALE(volume_ratio / (SUM(volume_v, 20) / 20))
```

> **与官网 Python 模式的差异**：官网要求 `class CustomFactor(Factor)` + `calculate(self, factors)`，
> 通过 `factors['close']` 取数、返回多级索引 Series。**本地做了简化**：不需要写类，
> 字段直接就是变量（`close` 即面板），把结果赋给 `factor_data`（或 `df_factor`）即可，
> 官网示例中 `calculate` 内部的计算逻辑可原样搬过来。

## 六、与官网的差异核对结论（汇总）

| 项目 | 官网 | 本地 | 说明 |
|------|------|------|------|
| Python 编写模式 | `class CustomFactor(Factor)` + `calculate` | 直接赋值 `factor_data = ...` | 计算逻辑可原样迁移，无需类模板 |
| `SCALE(X)` | minmax 缩放至 [-1,1] | Alpha101 语义：绝对值和 = a | 因子库 Alpha 公式依赖后者 |
| `WR` / `CCI` / `ATR` | 单序列签名 `(X,N)` | 需传高低收面板 | 官网内部隐式取高低价，本地显式传入 |
| `turnover` / `market_cap` 字段 | 可用 | ❌ 暂不可用 | QMT 日线缓存仅量价 |
| 财务/估值字段（330+） | 可用 | ❌ 暂不可用 | 待接入 QMT 财务数据 |
| 其余全部函数 | — | ✅ 已实现 | 与官网手册逐项对齐 |

## 七、示例：把因子库公式搬到工作流

1. 在因子库点击任意 Alpha 因子 → 详情弹窗「公式」页复制公式（或代码）。
2. 工作流中拖入「因子构建（公式）」节点，把公式粘进去，配置股票池与起止日期（无需上游数据节点）。
3. 下游接「因子分析」节点（或「IC 计算 / 分组收益」），运行后在节点上点击**「查看分析报告」**
   即可打开完整综合报告（数据卡 14 项指标、分组绩效、IC/Rank_IC 全套图表、AI 综合分析）。

因子库中「财务/估值」类因子为数据字段型条目，本地暂无财务数据支撑，仅作参考。
